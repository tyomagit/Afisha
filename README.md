# Афиша мероприятий «Вне дома»

Учебный сайт-каталог городских событий. Автор — Мацейко А. В.

Группа — впишите перед сдачей.

## Запуск

Откройте `index.html` в браузере. Для просмотра через локальный сервер запустите из корня проекта:

```sh
python3 -m http.server 8000
```

Сайт откроется по адресу `http://localhost:8000`. Для запуска не нужны сборка, npm или бэкенд. Расписание, цены и заявки демонстрационные. Формы проверяют поля в браузере и не отправляют контактные данные.

## Страницы

| Файл | Содержимое |
| --- | --- |
| `index.html` | Баннер, подборка популярных событий, категории, преимущества и якорные ссылки |
| `catalog.html` | Карточки с фотографиями и фильтры по названию, категории, дате и стоимости |
| `product.html` | Описание, расписание, площадка, таблица билетов и кнопки заявки |
| `order.html` | Выбор события и форма заявки |
| `contacts.html` | Сведения о проекте, форма обратной связи и частые вопросы |

Общее меню, подвал и кнопка «Наверх» есть на всех страницах. Внутренние страницы содержат хлебные крошки. У каждой страницы есть свой заголовок и метаописание.

## JavaScript

- `js/events.js` хранит данные шести событий.
- `initCatalog()` применяет фильтры и обновляет количество результатов.
- `initEventPage()` показывает выбранное событие и его таблицу билетов. Событие определяется по параметру `event` в адресе.
- `initForms()` проверяет поля и показывает результат валидации. Дата заполняется при выборе события.
- `initModal()` открывает форму из карточки и возвращает фокус на кнопку после закрытия.

## Проверка

1. Откройте каталог. Выберите «Бесплатно». Должны остаться «Новая оптика» и «Городской маркет».
2. Добавьте поиск по названию и затем сбросьте фильтры. Должны вернуться все шесть событий.
3. Откройте «Между строк». Проверьте описание, дату и таблицу, затем перейдите к заявке.
4. Нажмите «Записаться» на карточке. Модальное окно заполнит выбранное событие и дату. Проверьте обязательные поля и закрытие по Esc.
5. Уменьшите ширину окна. Карточки, форма и меню должны оставаться доступными. Проверьте переходы с помощью Tab.

## КР №2 и практики 9–11

Отдельная реализация афиши на Bootstrap 5.3.8. Bootstrap CSS и JS Bundle хранятся в `vendor/bootstrap/`, собственное оформление — в `css/custom.css`.

| Компонент | Где используется |
| --- | --- |
| `container`, `row`, `col-*`, `g-*` | Главный баннер, сетки карточек, каталог и детали |
| `navbar`, `collapse` | Адаптивное меню |
| `card`, `btn`, `badge` | Карточки и кнопки действий |
| `form-control`, `form-select`, `form-check`, `input-group` | Формы и поле количества билетов |
| `modal` | Быстрая заявка |
| `alert` | Результат валидации и пустой каталог |
| `accordion` | Частые вопросы |

Самостоятельные доработки — локальное подключение Bootstrap, дополнительная страница контактов, фильтрация каталога, подстановка события в форму и адаптация под телефон.

## GitHub и GitHub Pages

В архиве уже есть локальный репозиторий Git с веткой `main`, ветками разработки и коммитами. Проверьте историю:

```sh
git status
git log --oneline --graph --all
```

Как создать отдельный репозиторий GitHub и показать Pull Request:

1. Войдите в GitHub CLI с помощью `gh auth login`.
2. Выполните команды из этой папки. Они создают **новый публичный** репозиторий. Если одноимённый репозиторий уже есть, используйте свободное имя или укажите нужный пустой репозиторий как `origin`.

```sh
gh repo create kr2-bootstrap-shop --public --source . --remote origin
git push origin coursework-start:refs/heads/main
git push -u origin feature/afisha-submission
gh pr create --base main --head feature/afisha-submission --title "Афиша мероприятий" --body "Пять страниц, каталог, формы и адаптивная вёрстка."
```

3. Откройте созданный Pull Request на GitHub и объедините его с `main` через **Merge pull request**. Затем в репозитории выберите **Settings → Pages → Deploy from a branch → main → / (root)** и сохраните настройку.
4. Когда GitHub покажет адрес сайта, добавьте его в этот README и сделайте коммит. Для отправки последующих изменений сначала обновите `main`: `git switch main` и `git pull --ff-only origin main`.
5. В СДО сдайте ссылку на репозиторий. Добавьте ссылку на GitHub Pages, если она требуется преподавателю.
